# Contributing

Thank you for helping improve Kali NetHunter Pro support for Spacewar.

## Ways to Contribute

- Test development builds
- Report reproducible bugs
- Improve documentation
- Test hardware functionality
- Improve build configuration
- Submit fixes and patches

## Bug Reports

Include the information requested in [docs/troubleshooting.md](docs/troubleshooting.md).

A good report is reproducible and contains logs where possible.

## Pull Requests

For code/configuration changes:

1. Explain what changed.
2. Explain why it is required for Spacewar.
3. Include testing details.
4. Avoid unrelated changes.
5. Do not include large generated binaries.

## Responsible Testing

Only test security functionality on systems and devices you own or are explicitly authorized to test.

## Upstream Work

Where a change belongs in the upstream Kali NetHunter Pro project, consider submitting it upstream rather than keeping a long-term device-specific workaround here.
