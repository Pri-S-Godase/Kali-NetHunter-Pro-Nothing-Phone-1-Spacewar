## Testing Method

For each hardware feature, record:

- ROM version
- Android version
- kernel version
- NetHunter image version
- test procedure
- result
- logs/errors

Avoid marking hardware as supported based only on the fact that Android supports it. NetHunter Pro/Linux compatibility must be tested independently.
